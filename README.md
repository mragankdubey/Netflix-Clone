Netflix Clone

A responsive Netflix landing page clone built using HTML and CSS.

This is my first web development project, created to practice building modern, responsive user interfaces by recreating the look and feel of the Netflix homepage.

🚀 Features

- Netflix-inspired landing page
- Responsive layout
- Modern UI using HTML & CSS
- Clean and organized code
- Hover effects and styling similar to the original website

🛠️ Tech Stack

- HTML5
- CSS3

📂 Project Structure

Netflix-Clone/
│── index.html
│── style.css
│── images/
└── README.md

💻 How to Run

1. Clone the repository:
   
   git clone https://github.com/your-username/Netflix-Clone.git

2. Open the project folder.

3. Double-click "index.html" or open it in your browser.

📚 What I Learned

- Structuring web pages with HTML
- Styling layouts with CSS
- Using Flexbox for alignment
- Creating responsive designs
- Improving UI design by recreating a real-world website
